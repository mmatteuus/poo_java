# Exercícios de Programação Orientada a Objetos em Java

Coleção de exercícios desenvolvidos para praticar lógica de programação e os principais fundamentos de orientação a objetos com Java.

## Conceitos praticados

- classes, objetos e encapsulamento;
- composição e relacionamento entre entidades;
- coleções e filtros;
- manipulação de textos;
- organização de responsabilidades;
- regras de negócio simples;
- construção de pequenos programas de console.

## Conteúdo

### Texto e frase

Exercícios com substituição de termos, contagem de palavras, estimativa de tempo de leitura, filtros e seleção aleatória.

### Catálogo de mídia

Modelagem de entidades como filme, série, tema e artista, com filtros encadeados e combinação de resultados.

## Tecnologias

- Java
- Programação Orientada a Objetos
- Aplicações de console

## Objetivo

O repositório registra minha evolução nos fundamentos de Java e serve como base para projetos maiores envolvendo interfaces, persistência de dados e APIs.
